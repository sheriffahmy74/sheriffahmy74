### About Me

I'm **Sherif Fahmy**, a **Flutter Developer** and the **Founder of Lamma** — an experience discovery and planning platform helping people in Egypt find and plan outings, day trips, workshops, and community meetups, with an MVP launching first in **Cairo** and **Mansoura**.

I build mobile products end‑to‑end — architecture, UI, backend integration, and shipping to production — with a focus on clean code and interfaces that feel considered, not templated.

- 📱 Building with **Flutter & Dart**, shipping to **Google Play** and the **App Store**
- 🧠 Clean **Architecture**, **MVVM**, **Bloc / Cubit**
- 🔥 **Supabase**, **Firebase**, realtime data, **Google Maps**, payment integrations
- 🔗 REST APIs, scalable code structure, maintainable features
- 🎨 Obsessive about UI polish and smooth UX
